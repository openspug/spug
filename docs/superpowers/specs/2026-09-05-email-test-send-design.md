# 邮件测试实际发送设计

## 问题

设置页的“测试邮件服务”目前只建立 SMTP 连接并认证，没有发送邮件，因此接口会返回成功但用户收不到测试邮件。

## 方案

- `email_test` 使用表单中的 SMTP 配置构造 `Mail`，将测试邮件发送到 `username` 本身。
- 可选的 `nickname` 一并传入，保证测试行为与正式报警邮件一致。
- 复用 `Mail.send_text_mail`，由其负责 SMTP 连接、认证、标准邮件头、发送及关闭连接。
- SMTP 抛出的连接、认证或发送错误继续作为接口错误返回；只有 SMTP 接受邮件后才返回成功。
- 前端成功提示明确为“测试邮件已发送，请检查收件箱和垃圾邮件”。

## 测试

- 后端测试从 HTTP 视图入口验证测试邮件确实发送给登录邮箱，且主题和正文明确标识为测试邮件。
- 后端测试验证 SMTP 发送异常会返回错误而非成功。
- 前端只调整成功文案，不改变表单结构。
